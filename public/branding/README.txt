C-SPARKZ EMPIRE — parent-company brand assets
================================================

Place the OFFICIAL approved C-SPARKZ EMPIRE logo files here, using these exact
filenames (referenced by src/config/brand.js and CSparkzEmpireBrand.jsx):

  c-sparkz-empire-logo.png               Full lockup (monogram + wordmark), opaque background
  c-sparkz-empire-logo-transparent.png   Full lockup, transparent background (preferred for UI use)
  c-sparkz-empire-mark.png               Monogram/mark only (no wordmark), for compact placements

Do not substitute with a generic logo, crown, globe, text-only wordmark, or a
different C/S symbol — use the approved gold-monogram-on-black design only.

Until these files are added, the brand component gracefully falls back to a
text-only "Powered by C-SPARKZ EMPIRE" credit (no broken image icon).

Recommended format: PNG with transparency, or SVG if a vector version is
available. Keep file size small (<100KB) — this asset loads on every page.
